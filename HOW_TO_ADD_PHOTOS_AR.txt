طريقة تغيير صور الشخصية بشكل مستقل:

داخل assets/gallery-uploads/characters/vincent (أو مجلد أي شخصية):
card.jpg = صورة بطاقة الشخصية في الصفحة الرئيسية.
cover.jpg = الصورة الكبيرة داخل صفحة الشخصية (تُستخدم افتراضيًا إن لم توجد profile.jpg).
profile.jpg = صورة البروفايل داخل صفحة الشخصية؛ تتغلب على cover.jpg عند وجودهما.
dossier-card.jpg = الصورة على البطاقة القابلة للقلب داخل ملف الشخصية.

يمكن استخدام PNG أو WEBP بدل JPG بنفس الاسم. لا تُضاف هذه الصور الخاصة إلى المعرض العادي.
إذا لم تضعي أي ملف من هذه الملفات تبقى الصورة الأصلية دون تغيير.

لإضافة صور المعرض: ضعي الصور بأسماء أخرى داخل مجلد الشخصية أو مجلد Moments المناسب، ثم Commit وPush من GitHub Desktop. يقوم GitHub Actions بتحديث قائمة الصور تلقائيًا.

مجلد needs-sorting يحوي صورًا مسترجعة غير معروفة التصنيف؛ انقليها إلى المجلدات الصحيحة بعد مراجعتها.
لا تحذفي assets/images أو الملفات الأصلية.

إصلاح Moments: يتجاهل البرنامج الصور المكررة المطابقة بالملف نفسه، حتى لو كان اسمها مختلفًا.
إذا كان ملف صورة قديم مفقودًا، يخفي الموقع البطاقة المكسورة بدل عرضها.
لتجربة التعديلات محليًا: python scripts/build_gallery_manifest.py ثم python -m http.server 8000 وبعدها Ctrl+F5.
